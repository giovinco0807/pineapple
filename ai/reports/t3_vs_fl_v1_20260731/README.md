# T3-vs-FL v1: 学習は通るが行動選択で不合格 (2026-07-31)

## 結果

| 指標 | 値 | 参考(T4-vs-FL v2) |
|---|---|---|
| 教師 | 30k root / 353k行 / 5.4h(競合下) | 270k行 / 2.2分 |
| test相関 | 0.9306 | 0.9592 |
| test MAE | 0.429 | 0.641 |
| **最良手選択率** | **39.6%** | 94.8% |
| **mean regret** | **0.279** | **0.006** |
| regret p95 / max | 1.21 / 5.30 | — / 0.45 |

紙の上の指標(相関・MAE)は健全に見えるが、実際の用途である行動選択では
T4-vs-FL比で**45倍悪い**。ジョーカー層別ではjoker2が最悪(MAE 1.09, RMSE 2.48)。

## 診断

通常トラックのT4診断と同じ類型が、1ストリート上で再発している。
現エンコーダ(60次元)は自分の11枚盤面について「確定役・空き・順序スラック」
しか持たず、**空き2スロットの完成見通し(completion outlook)が一切ない**。
T3-vs-FLの行動価値はまさに「このボードがT4ドローで何になれるか」で決まる。

T4-vs-FLで機能した理由は、行動適用後にhero盤面が完成し厳密な終端事実を
特徴にできたから。T3では盤面が未完成で、その差がそのまま出た。
joker2層が最悪なのも、開いた盤面のジョーカー柔軟性を部分カテゴリが
表現できないためで、整合的。

## 対策(実装指定)

T3行動適用後の盤面は空き2——`opponent_joint_block`が扱う構造そのもの。
Rust側は`t3_second::joint_block`で既に安価に計算できる。

1. `t3_vs_fl.rs`のレスポンスに行動ごとの`own_joint_block`(8次元)を追加
   (foul率・joint EV・生存条件付きroyalty/FL・std・テール確率2・生存EV)
2. 教師生成器のエンコーダを 48+8+12=68次元(または行別完成ヒストグラムも
   足して109次元)へ拡張
3. 再学習→同一のregret検証(目標: mean regret < 0.05)

教師の再生成はRustラベラが0.56s/rootなので約5時間(競合なしなら短縮)。
