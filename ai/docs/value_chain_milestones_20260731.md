# 価値チェーンAI 実装マイルストーン (2026-07-31)

設計: 探索・方策ネット・MCTSを使わず、各ターンの価値関数を厳密解から下へ
アンカーして積み上げ、全ターンを「合法手全列挙 → 評価器 → argmax」で打つ。
確定事項は以下(いずれも実測済み):

- T4後攻=閉形式厳密、T4先攻=厳密6ms/root、評価器ノードMAE 0.159
- T3後攻=評価器を葉にして厳密比 相関0.991 / MAE 0.30
- 評価の誤りは探索量で救えない(20,000シミュレーション実験)
- 誤差診断→実ハンド精読→厳密計算可能な事実の特徴化、のループは機能する
- T2以上のラベルは値ブートストラップではなく**チェーン・プレイアウトの終端スコア平均**
  (段数に対して誤差が複利で増えない)

## FL EVの扱い(循環の明示)

FL EVは最適方策に依存し、最適方策はFL EVに依存する。**一発では計算できない。**
ただし固定点は「FLサブゲーム」内で閉じる: FL EV(n) を決めるのは
(a) FL側の最適配置(fl_solver・厳密)、(b) normal-vs-FL方策の盤面分布、
(c) stay率と連鎖、のみ。通常vs通常方策はFL EVを消費するだけで定義に入らない。

よって **M-B/M-C を反復して FL EV を収束させ、高価な通常チェーン(M-D以降)は
収束後テーブルで1回だけ構築**する。現行 fl_ev.json はv0(初期値)として使う。

## マイルストーン

| ID | 内容 | 完了条件 | 目安 |
|---|---|---|---|
| **M-A** | FL基盤・速度回復 | fl_solver 2段化(生値プレフィルタ→上位Kを正典確定)で2.4s→数十ms/手。audit 400手で不一致0維持。条件付きFL盤面バンク生成器 | 0.5〜1日 |
| **M-B** | FLサブゲーム・チェーン | normal-vs-FL の T4→T0(自分ハンドのみの特徴・相手ブロックなし)。下段は厳密、上段はプレイアウト・ラベリング。FL-vs-FLは両者盤面分布の直接畳み込み(方策不要)。各段で厳密スポット照合 | 2〜4日 |
| **M-C** | FL EV固定点反復 | FL_EV_v(k) → M-B再学習(軽量) → FL側スコア分布+stay率 → v(k+1)。全エントリ\|Δ\|<0.5点で収束、hash付き凍結。2〜3周想定 | 1〜2日+計算 |
| **M-D** | 通常チェーン下段の再構築 | 確定FL EVでT4先攻教師再生成(約1h)+再学習、T3後攻教師再生成(約5h)+学習。T3先攻(応手=後攻評価器argmax)を追加し、サンプル厳密解との行動一致率で照合 | 3〜5日 |
| **M-E** | T2〜T0 プレイアウト・ラベリング | T2後攻/先攻→T1→T0。ラベル=下位チェーンで終端までプレイアウトした厳密スコア平均。T0はオンライン深化(サンプルドロー×チェーン先読み)も許容 | 1〜2週 |
| **M-F** | pass 2(on-policy)と検証 | root分布 on-policy70/一様20/敵対10 で全段貼り直し。FL EV再確認(変動小のはず)。paired self-play vs 現行本番、T4/T3厳密regretアンカー、ターン×席×Joker層別TVで収束判定 | 1週+計算 |

合計目安: 4〜6週。GCPはM-E/M-Fの規模次第(Rust化済みのため1台効率は高い)。

## 段ごとの棄却条件(事前宣言)

1. T3先攻の行動一致率がサンプル厳密解に対して急落(後攻の0.991相関から大幅低下)
2. プレイアウト・ラベルのT2評価器が厳密スポット検査で系統的バイアス
3. pass 2のon-policy分布でpass 1評価器が崩壊(深刻な分布シフト)

いずれかが出た段だけ、厳密教師を深くする(計算をGCPへ)方向に切替える。
周回数を増やして解決しようとしない。

## 使わないもの(根拠つき)

- MCTS/PUCT: 評価が誤っていれば探索は最適に誤る(20,000sims実験)
- 方策ネット/BC: Top-1天井30〜59%の実績。値のargmaxが方策
- 自己対戦の勝敗からのVN学習: ノイズ天井(相関0.79)の再現になる
- 全面MCCFR: 隠れ情報が捨て札≤3枚のゲームに対して不釣合。捨て札尤度の
  再重み付けを最終改修候補として保留(exploitability probeで必要性を測ってから)
