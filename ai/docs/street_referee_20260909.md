# 街×席の審判集合 (2026-09-09 開始)

オーナー裁定(9/7)「審判は今後のモデルの強さを測る指標にする」を、T0 以外のモデル決定スロットへ広げる。
T0-BB 戦役の結び(`t0bb_campaign_20260907.md` §7)で「T1 以降へ移る」を推奨し、9/9 に「はい」で着手。

## 1. 対象と根

モデルが決めるスロット: T1・T2 の両席と T3-BB(T3-BTN・T4 は厳密解)。席 0 = BB(各街の先手)、席 1 = BTN。
根は 20260904 チャンピオンの自己対戦トレース(`tr3_traces_20260904/0000.jsonl`、2万ハンド)の実決定そのもの:
(ハンド, 街, 席)。深層再生審判 `--hu-deep-replay` がその決定の直前まで盤面を復元し、**合法配置すべて**
(T1/T2 は 27 手、T3 は 12〜21 手)を own_fl でレースする。柵は不要(全手にラベル)。
`served` はトレースが記録した実際の盤面 = チャンピオン(柵 K=4 + 評価器)の決定。

集合: スロットごとに 480(無作為 240 + ヒーローの可視札にジョーカーを含む 240)。
`ai/tutor/hu_street_roots.py`、シード帯 9.5e9。素材 `D:/ofc_data/hu/street_sharp/roots_t{S}s{T}.jsonl`。

## 2. 道具

- `t0_btn_label.py --street S --seat {bb,btn}`: 根の `trace` を1ハンドのファイルに書き、`--hu-deep-replay --replay-hand 0
  --replay-street S --replay-seat T` で列挙とロールアウトを行う。場は全手、レース停止則は T0 と同じ。
- 艦隊: `launch_t0_label_fleet --street S`(metadata `hu-street`)、`startup_t0_label.sh` が `--street` を渡す。
  ソース `hu_src_20260909a.tar.gz`、バイナリ binstamp 20260905a(Parts 対応)。台本 `/c/tmp/leakmap/launch_street_race.sh`。
- 指標: **served の regret** = 審判最善値 − served の値(1決定あたり)。これがそのスロットのチャンピオンの漏れ。
  候補モデルの採点(柵内 argmax)は街用の符号化器が要るため、候補ができてから。

ローカル検証: T3-BB 2 局面(cap 256)で列挙 21 手、served = 最善、2.4 分。
