## 事故と教訓 (2件、いずれも運用知識として本文より重要)

1. **モデルtarはオブジェクト名のラッパーディレクトリごと固める。**
   `tar -czf x.tar.gz -C dir a b` (フラット) で固めたら、startup は作業ルート直下に
   展開し match引数の `models_t2r1/...` が全て不在 → **40台全機が起動直後に死亡**。
   さらに match VM の SA は self-delete 権限が無い (既知) ので**3時間ゾンビ滞留、~$26損**。
   検死: `runs/<run>/logs/` に trap が必ず startup.log を出荷している (「models: 0
   evaluators」の行が決定打)。progress マーカー (deps_ok→artifacts_ok→無音) で段階を特定できる。
2. **ミラーゲートは起動込み~10分で終わる。** 「2.5-3時間」は誤認 — g1 の物証
   (deps_ok 10:01Z → 全20シャード 10:03:40-10:04:07Z に一括着弾) が正。前回は完走後
   放置していた時間を対戦時間と混同した。以後のゲートは投入15分後に回収に行く。
