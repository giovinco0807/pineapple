# 街×席の失点地図 — 出荷モデル対・順位付け可能なteacher (2026-08-21)

> **2026-08-22 訂正(先に読むこと)**: T1〜T3の「4σ確定誤り」率は**約1.7倍過大**。
> ローカル停止則(3バッチ以降、経験的SEで|t|≥4なら即決)は、小標本のtが
> t分布の太い裾を持つため偽陽性を混入させる(自由度2で P(|t|≥4)≈5.7%)。
> GCP艦隊のT2後攻 n=3,600 で実証: **固定8バッチ判定=3.4%、逐次判定=同一データで5.9%**。
> 真のT2後攻: **誤り3.4%±0.6pt、gap平均0.958、漏れ≈0.033点/ハンド**(0.071ではない)。
> 各マスの相対順位は概ね保存されるが、絶対値は固定深度で読み直すこと。
> T0後攻は定数ベースの消去法+個別深掘り(p01 4.4σ/p02 4.5σ)なので別勘定で有効。
> 逐次則で確定した個々の誤りのうち、gapが大きいもの(≳0.5)はほぼ真。小gapの
> 「確定」が疑わしい(T3後攻の0.005などはこの機構の産物と見るべき)。

一晩で6マスを測った。各マスの問いは同じ: **出荷チャンピオン(m7v5ピン)の一手は、
on-policyな局面で、粒子測定が確定させる最善手とどれだけ食い違うか。**

物差しの正体を最初に明記する。teacherは1手読みの方策改善演算子であり
(ロールアウト内の全継続は現行ピンのモデルが打つ)、真値ではない。この地図の数字は
**teacher尺度の下限風の見積もり**で、最終的な合否は対戦ゲートが下す。役割は
「対戦という高価な審判を呼ぶ回数を8回から1〜2回に減らす」こと。

## 完成した地図の読み (2026-08-22)

**席あたり合計(teacher尺度の下限風):**

```
先手のリーク合計: 0.029 + 0.062 + 0.020 + 0.016 = 0.127 点/ハンド
後攻のリーク合計: 0.073 + 0.041 + 0.071 + 0.025 = 0.210 点/ハンド
平均                                              ≈ 0.17 点/ハンド
```

1. **後攻は先手の約1.7倍漏れる。** 率で見るとT2(8.3% vs 3.3%)とT3(7.5% vs 3.3%)は
   後攻が2倍超。相手の盤面情報が増えた席ほど上位序列が乱れる、が一貫した傾向。
2. **EV加重では T0後攻(0.073)と T2後攻(0.071)が2大マス。** T1がそれに次ぎ、
   T3は率こそ高いがgapが小さく(平均0.34、最小0.005)実害は小さい。
3. T3の「4σ確定」には gap 0.005〜0.1 の微小案件が混ざる——T3はバッチが安く経験的SEが
   締まるため、実害のない差でも統計的に確定する。率でなくEV加重(漏れ列)で読むこと。
4. 現行チャンピオンの対BCグリーディ優位が約+1.09/ハンドであることに対し、
   teacher忠実度の残り伸びしろは合計~0.17/ハンド(その上限は不明のまま——teacherは
   1手読みなので、真の伸びしろはこれより大きい可能性がある)。

漏れ = 確定誤り率 × gap平均。n=120の率の95%CIは±2.5〜5pt(Wilson)。
n=24のT0後攻は[2.3%, 25.8%]と幅広く、序列の主張には使えない。

**読みどころは2つ。**

1. **T0→T2先手は単調減少**(0.073→0.062→0.041→0.020)——深い街ほどモデルは
   teacher水準に近い。既知の傍証と整合(T2モデルは88根で誤順序ゼロの記録、
   docs/t3_tie_misses_20260815.md:534)。
2. **T2後攻だけ壊れる**(8.3%、T2先手の2.5倍)。相手9枚を見た判断の席。
   確定誤り10件は一晩で最多。ここが次の深掘り先。

## 確定誤り29件の共通構造

- **チャンピオンの手は29件全てモデル1位**(decide≡model_scores、全480局面で維持)
- **正解は29件中28件がモデル5位以内**(2位×15、3位×6、4位×4、5位×3)。
  例外はT1後攻p104の10位(gap +1.774)のみ
- 型は繰り返し「段構成の圧力を跨いだ1位2位の入れ替え」:
  33をミドルに立てるかボトムに沈めるか(T0後攻p02、+1.23)、
  ペア温存かファウル圧回避か(T1先手p035、9d9s中置きvs 9s捨て、+2.37)、
  Aの早期トップ飾りかボトム厚み優先か(T0後攻p01、+0.52)

**含意**: 漏れは「モデルの上位数手の順序間違い」に集中しており、実戦時に
top-K(K≤10、大半はK≤5)を粒子検証する探索で構造的に全量拾える。
ラベル・容量side の欠陥ではない(T3残差調査の結論とも整合)。

## 方法(再現に必要な最小限)

局面: チャンピオン自身に前の街を打たせたon-policy標本(seed 94M/95M/96M/97M台、
     120局面/マス)。既存のbehavior roots(凍結旧方策+randomが混入)は使わない。
測定: 全ファン(T1/T2は27手)を共通乱数バッチ(256p)で採点し、
     チャンピオン対リーダーの対差gapを**経験的SE**(バッチ間散らばり)で判定。
     3バッチ以上で|t|≥4なら確定、最大8バッチ(2,048p)で未決なら「未決着」。
     T0の雑音定数0.475は他街へ持ち込まない(T1実測の換算値は約0.37@1,024p)。
T0後攻のみ: restrict_action_keys(worktree版エンジン)+ hu_t0_sequential_elimination_v1、
     モデルtop-32絞り込み、予算8,192p。
道具: scripts/street_gate/ に一式(gate2_* = T0後攻、t1_* / t2_* = 各街)。
生データ: D:/ofc_data/t0_rung/{gate2_t0second, t1_gate, t2_gate}/。

コスト: 全6マス、ローカルのみ、$0。壁時計 約20時間(5ワーカー×RAYON 3)。

## 踏んだ罠(全て実際に起きた)

1. **トレーナー段のT0評価は候補あたり1世界**で順位付け能力がない。最初の探針は
   チャンピオンを「中央値114位/232」と報告した——teacher側の雑音である。
   deep_t0=(2,4,1)ですら232候補中41しか分離しない(engine_eval.py:98)。
2. **restrict_action_keysはevaluate_t0にしか配管されていない**(search.rs:4315のみ)。
   T1+は全ファン再評価が正しい(幸い扇27は平坦域)。
3. **候補詰め込み4倍説は幻**。実測カーブ(n=616バッチ)は5候補で底、32まで平坦
   (0.05前後)。probe arm2の結論どおり、効くのはスレッド数がファンを割り切ること
   (20%)。粒子は厳密線形〜超線形(4,096pで×4.25)。
4. **bash製の番人はランチャー終了と道連れに死ぬ**(pythonワーカーは生き残る)。
   無人連鎖はMonitor通知→直接起動で行う。
5. **バッチ書き込みパスの更新漏れ**(t2_gate_b初版)で毎バッチb00を上書き。
   判定はメモリ上の系列で正しく、doneマークは有効。T2先手のバッチ・アーカイブと
   T2後攻の再起動前約30局面ぶんは失われた(深掘りには再測定が要る)。
6. GCSタイムスタンプはUTC、ローカルはJST。突き合わせずに読むと9時間ずれる。
