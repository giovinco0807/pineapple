# HUレギュラー: 現在地と今後の方針 (2026-08-18)

2026-08-15〜18の実測の総括と、ジョーカー側の再生産設計
(`ai/docs/hu_regen_distill_ladder_20260818.md`) から流用する規律の適用。
数値は全て実測。

## 0. 一行の要約

**対戦だけが採点。中間指標で買い物をしない。**
T1後攻を25,000 rootに戻して対戦で決着させ、その結果がT0への支払いを決める。

## 1. 確定した事実

### ラベル (T1リラベル, fl_ev 9.6)

- 両席コーパス完成・検証済み: 各**18,000 root × 256粒子 × 全27手**、
  offset重複0・plan_sha一致・fl_ev={"14":9.6}全行。
  `D:\ofc_data\t1v2\{second,first}`、プラン `365d23d8…`(後攻)
- リラベルの前提は真: 定数10.227→9.6で同一root・CRNの1位が**21%**変わる
  (τ=0.8919)。幅だけが順位を動かし、T1はFL進入が最も不確実な街

### 再学習と対戦 — 中間指標と対戦が割れた

| | 保留regret (新ラベル基準) | ミラー1,500ディール |
|---|---|---|
| 後攻 v2 | 0.1964→**0.1808** (+0.0156) | **−0.0705** (凍結lrでは−0.1240) |
| 先攻 v2 | 0.1807→**0.1700** (+0.0107) | −0.0219 (凍結lrでは−0.0092) |

教師の写しは良くなったのに対戦は良くなっていない。学習率は無罪
(凍結1e-3でも同符号)。ミラー健全性は両方通過(一致ディールは厳密0.0)。

### 切り分け — 犯人はroot数

旧コーパス(fl_ev 10.227, 25k root)で、プロトコル固定・root数だけ変更:

| | 18,000 | 25,000 | 差 |
|---|---|---|---|
| 後攻 | 0.1707 | **0.1547** | **0.0160** ≒ リラベル利得(+0.0156) |
| 先攻 | 0.2042 | 0.2019 | 0.0023 (無感応) |

**後攻は「定数変更の利得」を「18kへの削減」がちょうど相殺**。
サイジング時の「曲線は25kの手前で寝る」はラベル品質の話で、
現行モデルが25kで学習済みという事実を勘定に入れていなかった。
先攻はroot数に無感応で、ゲートもほぼゼロ — 席別の挙動が両測定で一致。

### 葉の打ち切り (T3, 12root, 1024粒子, root/候補/シード共有)

| 葉 | 失う値 | コスト |
|---|---|---|
| プレイアウトして採点 | 0.0064 | 基準 |
| T4をモデルが**選ぶ** (現行T1の設計) | 0.0271 | **66倍安** |
| モデルの**値**で打ち切り | 0.1002 | さらに安 |

機序: 選び誤差は候補間で共通に近く相殺、値誤差は候補ごとに違い順位を直撃。
1 rootのスモークはτ=1.0000を出したが12rootで0.9461 — 順位統計に1rootは無効。

### T0

- **後攻**: 232手、**507 core-s/root** (256p本番設定) → 18k換算 2,535 core-hours ≈ **$75**
- **先攻**: コスト測定は**未決着**。8/16/32粒子で83s/評価の実測がある一方、
  同一設定(32p·同シード)が900s超、128pが3時間超で未完。
  同じ計算が83s→900s+に揺れるのはアルゴリズムでなく**マシン状態と交絡**
  (該当時間帯は`tasklist`すら2分無応答 — メモリ枯渇疑い)。
  **クリーンな環境で再測定するまで、T0先攻の値付けは信用しない**

- T0教師の下位街ピンは全て世代1 — **T1 v2の着地が先行条件**(順序は動かせない)

## 2. ジョーカー文書から流用する規律

流用するのは**数値でなく規律と順番**(教師構造が違う: あちらは厳密V4境界の直読み、
こちらは終端までのプレイアウト+レース)。

1. **対戦だけが自分を騙せない指標** — あちら「全指標良好のまま実戦で負けた前科」、
   こちら「保留regret改善+ゲート負け」。同じ現象を両トラックで独立に確認
2. **昇格の門**: MAEでなく**順位一致**で照合し、世代ごとに必ず対戦で採点
3. **T0の順番** (あちら§7-1と同一の壁=相手初手232配置):
   **T1まで直して先に対戦。閉じなければT0に払う**
4. **y-swap**: 同一rootの再ラベルでは特徴行列を再利用しyだけ差し替え。
   書き込み前3照合(root列一致・旧値一致・完全被覆)、失敗したら書かない
5. **kill後の部分ファイルは必ず消す** (再開ガードが「完了」と誤認)
6. 境界ネット構想 = 「値による打ち切り」のあちらでの成立形。成立3条件が明確:
   **厳密な地面(V4誤差<1e-9) / 境界ネットが削減不能床に接地(8.27 vs 床8.05) /
   昇格前の順位一致ゲート**。こちらは3条件とも未整備 → 当面封印
   (あちらでもT2は深さ壁で失敗しており街依存)

## 3. 方針

### 直近 (順番厳守)

1. **T1後攻 +7,000 root** (~$5, フリート40分+回収10分)
   - 新プラン必須: hand blockは952,000,000〜952,018,000と**非重複**の新規割当、
     eval seedも新ブロック、write-once。m7v6パッケージ再利用
2. 併合25,000で再学習 (warm start。凍結lr 1e-3と1e-4の両方を焼く)
3. ゲート2段: **1,500ディールのフィルタ**(~1.5h, CI±0.16)
   → 通過なら**20,004ディールの本ゲート**(~18h, 基準: 下側CI>−0.05かつ平均≥0)。
   保留regretでは選ばない
4. 先攻は18kのまま(root無感応)。**後攻の本ゲートが通ったら**チェーン整合のため
   先攻も本ゲートへ。通らなければ両席見送り・世代1維持
5. ピン時: T4M1書き出し→repo fixtures→trainer `WEIGHT_FILES`→順位一致照合を記録

### T0 (T1決着後)

1. まず**コスト異常の切り分け**: `wsl --shutdown`+再起動級のクリーン環境で
   壁プローブ(`t0_one_eval.py`×32/64/96/128×2シード、各900s上限)を再走。
   裾が実在するならフリート見積りが裾に支配されるため、**診断前のフリート投入禁止**
2. ラダー本体(`t0first_rung.py`)はコスト表確定後に規模を決める。
   evaluation_samples軸に加え**prefilter_samples軸**を測る
   (本番の順位列を動かすのはこちらの可能性)
3. 後攻$75/18kは参考値。先攻は診断後に値付け。支払い判断はT1本ゲートの結果を見てから

### 中期 — 周回の型 (あちら§7の移植)

世代2以降は毎周どれか一つを更新して1周回す:
**root分布のon-policy化 / ラベル内の相手モデルを現行に更新 / fl_evの再実測**。
同一root再ラベルはy-swap。採点は固定参照(世代1・前世代)との総当たりで共進化検知。

### やらないこと

- 値による葉の打ち切り (0.1002。§2-6の3条件が揃うまで)
- T3モデル強化の再開 (fitting limit 0.0296で決着済み)
- 中間指標だけでのピン
- n<3のシードやn<10のrootで順位統計を主張すること

## 決着 (2026-08-18 深夜)

**本ゲート不合格 — ピンなし、両席とも世代1維持。**

25k候補(凍結lr、held 0.1829)の20,004ディールミラー:
**平均 −0.0244、95%CI [−0.0777, +0.0289]**、分岐率12.2%、ミラー健全。
分岐したディール上の平均は−0.199/枚。基準(下側CI>−0.05かつ平均≥0)を両方満たさない。
1,500ディールフィルタの+0.0371は標本揺らぎだった。

これで「教師への忠実度が上がっても対戦は上がらない」の実証が3件目
(ジョーカー側の前科、T3の13.3%、今回のT1)。fl_ev 9.6への訂正自体は正しく
(順位の21%が動く)、実行も健全だったが、**現行チェーンに対する対戦優位には変換されない**。

- ラベル25,000root×2席は検証済み資産として残る(将来の周回で再利用可)
- **T0リラベルは棚上げ**: 同じ処方がT1で2度対戦に変換されなかった以上、
  $75+を払う根拠が消えた。再開条件は新しい機序(周回型の更新: on-policy root/
  ラベル内相手モデル更新/fl_ev再実測)の登場
- 残タスクはT0先攻のコスト揺れ診断(#17、$0)のみ
