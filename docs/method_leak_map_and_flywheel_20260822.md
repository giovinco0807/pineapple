# 手法: 失点地図とフライホイール — 別トラックへの移植指針 (2026-08-22)

レギュラー版で2026-08-21〜22に構築し、1回転を完走させた手法の一般形。
ジョーカー版(`ai/`)への移植を念頭に、**トラックに依存しない部分**と
**必ずそのトラックで測り直さねばならない部分**を分けて書く。

実装はレギュラー側 `scripts/street_gate/` と `scripts/m7_train/`。
実績は `docs/street_gate_leak_map_20260821.md`(地図)と
`docs/flywheel_rotation1_20260822.md`(回転1、+0.0403 [+0.0103,+0.0704])。

---

## 0. 何のための手法か

出荷モデルは「速い近似」であり、その上限は teacher(粒子ロールアウト)である。
だが **teacher は審判にならない** — ロールアウト中の継続手は現行モデル自身が打つので、
teacher は1手読みの方策改善演算子であって真値ではない。よって:

* teacher = **候補の値付け役**(どの手がどれだけ損か)としては使う
* teacher = **昇格の可否を決める審判**としては使わない。合否は対戦だけが決める

この分離が手法全体の背骨。忠実度(held-out regret)の改善が対戦に転写されない断絶を
レギュラー側は3回踏んでおり、4例目を避けるための構造である。

## 1. 失点地図 — どこに漏れがあるかを先に測る

### 1.1 手順(1マス = 1つの (street, seat))

```
A. on-policy局面をN個作る
     チャンピオン自身に前の街を打たせて到達した局面のみを使う。
     ランダム盤面や旧世代方策で作った局面は「実戦に出ない試験問題」であり、
     そこの正答率は失点と無関係。
B. その局面の全合法手を、共通乱数の粒子バッチで値付けする
     固定深度: R回 x P粒子(レギュラーは 8 x 256)。
     全候補が同じサンプル世界で戦うので、配牌の運は差し引きで消える。
C. チャンピオンの手 vs プール首位の対差を、R個のバッチ間散らばりから
   経験的SEで評価。|t| >= 4 で「確定誤り」。
D. マスの漏れ = 確定誤り率 x 誤り時のgap平均 (点/ハンド)
```

### 1.2 統計上の絶対規則(全部、痛い目を見て得た)

1. **逐次停止(peeking)を使うな。** 「3バッチ以降、|t|>=4になった時点で確定」は
   小標本 t の裾で偽陽性を量産する(自由度2で P(|t|>=4)≈5.7%)。同一データで
   逐次5.9% vs 固定8バッチ3.4% を実測。**判定は固定深度で1回だけ。**
2. **率でなくEV加重で読め。** 安いバッチの街ほどSEが締まり、gap 0.005 の
   無害な差でも「4σ確定」に入る。漏れ = 率 x gap で比べること。
3. **n=24級の比率は順位付けに使えない。** Wilson CI が [2.3%, 25.8%] になる。
   マス間の比較には最低 n=120、できれば n>=500。
4. **最大値を選んだ標本で、その最大値を主張するな。** 複数マスの最大を見つけたら、
   **別シード束で測り直して**からその値を引用する(選択バイアス)。
5. **1シード束のCIを信じるな。** 束を替えると符号が反転した前例がある(m7/m7b)。
   最低2束、束間差が3SE以内なら統合。
6. 定数ベースの停止則(あらかじめ実測したノイズ定数を使う消去法)は逐次でも安全。
   経験的SEの逐次だけが危険。

### 1.3 測定器の較正は「そのトラックで」やり直す

粒子ノイズ定数、1局面あたり単価、必要バッチ数は**街ごと・トラックごとに違う**。
レギュラーの実測値(T0の gap SD 0.475@1024p など)を別トラックに持ち込まないこと。
最初に数局面で測り直す。

## 2. フライホイール — 測った漏れを実際に減らす

```
採掘   : 地図と同じ装置を大量の局面に回し、確定誤りを集める
         1件 = 「局面 + 測定で確定した正解 + 全候補のEV」
再学習 : 元コーパス + 採掘した全局面 + 確定誤りのK倍複製
         → 現行チャンピオンから warm start、既存の凍結プロトコルで訓練
検収   : 汚染されていない別セットで候補を選ぶ(下記)
書出し : エンジンが読む重み形式へ
ゲート : 1スロットだけ差し替えたミラー複式対戦、2シード束、プールで判定
```

### 2.1 誤りだけを学習してはいけない

訓練の単位は「局面まるごと(全候補にラベル)」であり、順位学習は局面内の
数百ペアから学ぶ。確定誤りだけで微調整すると、**いま正しく打てている大多数を壊す**
(破滅的忘却)。正しく打てている局面も同じコーパスに残し、誤りは**複製で過重**する。
レギュラーの実績: 誤り121件を x16 で混ぜ、誤りの51%を矯正しつつ、
既に正しかった局面の正答率も 75.8% → 77.3% に改善(忘却なし)。

### 2.2 候補選抜は「汚染されていない」セットで

オーバーサンプル複製が混ざった held-out は、複製の多い候補を過大評価する。
レギュラーでは x8 と x16 を訓練し、汚染 held では x8 が優勢に見えたが、
清潔な3点検収(誤りセットの矯正率 / 元から正解だった局面の維持率 /
元コーパスだけの holdout)では x16 が全勝した。**選抜は清潔なセットで。**

### 2.3 ゲートの設計

* **1スロットだけ**差し替える(他は完全同一)。差が出たらそのスロットの寄与
* **ミラー複式**: 同じ配牌を席交換で2回打ち、per-deal の対差分を取る。
  これで分散が2桁落ちる(レギュラー実測 262倍)。**この対差分は必須**
* **同一決定のディールは厳密に 0.0 になること**を毎回検査する。
  ならなければ乱数か経路が壊れている(装置の自己診断)
* 2シード束・プール判定。基準はレギュラーでは
  「下側CI > -0.05 かつ 平均 >= 0」(非劣性)

## 3. 費用と時間の実測(レギュラー版、参考値)

| 作業 | 実測 |
|---|---|
| GCP艦隊での採掘(T2後攻) | 2.9分/局面、$40 / 3,600局面、60台で4.5時間 |
| 同(T1先手) | **26分/局面** — 街で9倍違う。較正必須の証拠 |
| ローカル採掘(T0後攻、232候補) | 約36局面/時(5ワーカー)、$0 |
| 再学習 | 90秒〜220秒(GPU) |
| ゲート 20,004ディール x 2束 | 5〜6時間、$0(ローカル) |

**街ごとに単価が桁で違う**ので、艦隊を出す前に必ず1VM・1ワーカー・1局面を
完走させて実測する(較正ゲート)。レギュラー側はこれを飛ばして$90を2回失い、
その後3回とも較正が事故を未然に防いだ(T1の見積もり2倍超の乖離を含む)。

## 4. 運用上の罠(トラックに依存しないもの)

1. **プランは現行チャンピオンのピンを継承させる。** 世代前のラベル生成器を
   流用すると、旧世代の継続方策で値付けされたラベルが混入する
2. **特徴量ダンプの入力仕様に注意。** レギュラーの dump は `runs[0]` しか読まない
   ため、R回のバッチはプールして1runに畳む必要があった。必須フィールドの
   取りこぼし(`skeleton`)でも落ちる
3. **オーバーサンプル複製が holdout をまたがないこと。** 分割が局面内容の
   安定ハッシュなら複製は同じ側に落ちるので安全。乱数分割なら破綻する
4. **bashの子プロセスはセッション回収で死ぬ**(WSL越しは特に)。長時間ジョブは
   ホスト側でデタッチしたプロセスに抱えさせる
5. 完走したVMは削除する。停止だけではディスクが課金され続ける
6. 承認済みゾーンでも、GCSに到達できないゾーンがある(症状: 生存かつ無出力)
7. **調査報告をそのまま設計文書にしない。** 本書と対になる
   `joker_port_plan_20260822.md` の初版は、検証していない報告を丸写しして
   実在しないAPI一覧を作った(8シンボル中8個が存在せず)。**引用する前に
   シンボルの実在を1つずつ確かめる。**「定数は必ずファイルを読む」の
   コード側の対応物。

## 5. ジョーカー版への移植チェックリスト

移植前に、そのトラックで **必ず確認・測定** すること:

- [ ] エンジンに「モデルの一手を返す」呼び出しと「候補群を粒子で値付けする」
      呼び出しがあるか。後者は全合法手を同じ世界で採点できるか
- [ ] on-policy局面を作れるか(チャンピオンで1ハンド流し、途中の観測を取り出せるか)
- [ ] 各街の**扇の大きさ**(ジョーカーはワイルドで候補が増える可能性)
- [ ] 1局面あたりの実測単価(街ごと)。レギュラーの値は使わない
- [ ] 粒子ノイズ定数(gapの散らばり)を数局面で実測
- [ ] 1スロットだけ差し替えられるゲートがあるか。per-deal 対差分を取っているか
- [ ] 同一アーム同士のミラーが厳密ゼロになるか(装置の健全性)
- [ ] モデルが存在しない/厳密解で置き換えられている街はどれか(そこはマス対象外)
- [ ] 訓練パイプライン(コーパス形式・warm start用checkpoint・書き出し器)の所在。
      レギュラー側はこれらがセッションの一時領域にしか無く、救出が必要だった

**測定を先にやること。** 地図が無いままフライホイールを回すと、漏れていない
マスに労力を注ぐ。レギュラーでは8マス中、実際に価値があったのは上位2マスだけで、
最小のマスとは4倍の開きがあった。
